# 🛒 Toko Sembako Segar

Website toko sembako online sederhana dengan fitur keranjang belanja.

## ✨ Fitur
- **8 kategori produk**: Beras, Minyak, Gula & Garam, Bumbu Dapur, Mie & Pasta, Minuman, Snack
- **18 produk** dengan harga realistis
- **Keranjang belanja** (localStorage) — tambah, kurang, hapus
- **Promo section** dengan diskon
- **Responsive design** — tampil bagus di HP & desktop
- **Tanpa framework** — murni HTML + CSS + JS

## 🚀 Cara Buka

**Langsung buka:**
```bash
# Buka di browser
open index.html
# atau
xdg-open index.html
```

**Server lokal (opsional):**
```bash
python3 -m http.server 8080
# buka http://localhost:8080
```

## 🛠️ Tech Stack
- HTML5
- CSS3 (CSS Variables, Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter)
- localStorage untuk keranjang

## 📱 Responsive
- Desktop: grid 4 kolom
- Tablet: grid 2-3 kolom
- Mobile: stack full-width
